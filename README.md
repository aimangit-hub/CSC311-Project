1. **Clone the repository:**
   ```bash
   git clone https://github.com/aimangit-hub/CSC311-Project.git
   cd CSC311-Project

   ```bash
   pip install -r requirements.txt
3. **Run the pipeline** by Openning Jupyter Notebook or Jupyter Lab and run sample.ipynb:
